# 🎀 Shreya's Birthday Surprise Website (v2.0) 🎂💙

An elevated, detailed, interactive pastel birthday surprise website handcrafted with HTML, CSS, and vanilla JavaScript. Designed specifically from the perspective of a CSE student crafting a unique, premium digital gift.

---

## 🎨 Theme & Strict Color System
The website strictly uses pastel blue and pastel pink as its primary colors across every single component:
* **Pastel Blue**: `#BDE0FE`
* **Pastel Pink**: `#FFC8DD`
* **Soft Baby Blue**: `#A2D2FF`
* **Light Blush Pink**: `#FFAFCC`
* **Card & Contrast White**: `#FFFFFF`
* **Readable Body Text (Soft Navy)**: `#3D4966`

## ✨ Upgraded & Detailed Features

1. **🎀 High-End Hero Opening Screen**:
   - Crisp modern typography: `"Hey Shreya! 🎀"` & `"So… someone just got a year older! 👀🎂"`
   - Dreamy glassmorphism panel, floating ambient balloons, and animated ribbon badge.
   - Smooth transition button `"Open Your Surprise 🎁"` with spring animations and celebratory fanfare.

2. **🎂 High-Fidelity Interactive Birthday Cake**:
   - Detailed SVG cake with layered shading, dripping frosting glaze, sugar pearls, and sprinkles.
   - **Interactive Flavor Switcher**: Switch between *🍓 Berry Blush*, *☁️ Sky Vanilla*, and *✨ Pastel Dream* themes!
   - 3 realistic glowing candles with subtle flame flicker animations.
   - `"Make a Wish ✨"` button: Blows out candles with animated rising smoke puffs, chimes, and triggers a multi-cannon pastel confetti explosion.
   - Displays: `"Wish big, birthday girl! 🥳"` and allows relighting the candles.

3. **💌 Elegant Birthday Letter**:
   - Opened cleanly via `"Tap for a Surprise 👀"`.
   - Displays Shreya's heartfelt birthday message inside a luxury pastel card with corner ribbons and a wax-seal emblem:
     > *"Happy Birthday, Shreya! 🥳🎂*
     >
     > *Hope your day is filled with happiness, laughter, good food, unexpected surprises, and all the things that make you smile. Keep being your awesome, slightly crazy self 😂. Wishing you lots of success, amazing memories, and a wonderful year ahead!*
     >
     > *Have the best birthday ever! 🎉"*

4. **💻 Developer Console: ShreyaOS (Authentic CSE Touch)**:
   *(Replaced the cheesy generic compliment cards with an authentic, witty developer experience!)*
   - Realistic pastel developer terminal with macOS-style window controls.
   - Tabs for `ShreyaConfig.ts` and `system_diagnostics.log`.
   - Interactive **`Execute benchmark()`** button that runs birthday unit tests, triggers particle sparks, and outputs celebratory benchmark logs.

5. **🔮 "The Year Ahead" Interactive Vibe Predictor**:
   - An interactive crystal ball widget.
   - Generates witty, non-cheesy, high-energy predictions for Shreya's upcoming year at the click of a button!

6. **🎊 Grand Finale Celebration**:
   - `"Happy Birthday, Shreya! 🎂🎉"`
   - `"Officially one year older, but still the same level of pagal 😂"`
   - `"Have an amazing year ahead. Keep smiling and keep being you! ✨"`
   - `"Celebrate Again 🎊"` button firing dual-barrel pastel confetti cannons.

7. **🎈 Interactive Balloon Pop Counter & Synthesizer**:
   - Click or tap any floating background balloon to pop it into sparkles with a real-time counter!
   - Built-in Web Audio API synthesizer for melodic chimes, candle blowout sounds, and balloon pops (zero external audio files needed).
   - Audio ON / OFF toggle button.

## 🚀 How to Run Locally

### Option 1: Direct File Open
Double-click `index.html` in your file explorer to open it directly in Chrome, Edge, Safari, or Firefox.

### Option 2: Python Local Server
To test on your mobile device over Wi-Fi:
```bash
python -m http.server 8000
```
Visit `http://localhost:8000` or `http://<YOUR_IP>:8000`.

## 🌐 Publish for Free on GitHub Pages

1. **Create Repository**: Go to [GitHub](https://github.com/), click **New**, name it (e.g., `happy-birthday-shreya`), and set it to **Public**.
2. **Push Code**:
   ```bash
   git init
   git add index.html README.md
   git commit -m "feat: Shreya's birthday surprise website v2.0"
   git branch -M main
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
   git push -u origin main
   ```
   *(Or drag-and-drop `index.html` via GitHub's web interface).*
3. **Turn on GitHub Pages**:
   - In your repo: **Settings** > **Pages**.
   - Under **Build and deployment** > **Branch**, select **`main`** and `/ (root)`.
   - Click **Save**.
4. **Live Link**: Available in 1-2 minutes at:
   `https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/`
